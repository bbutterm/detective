# adHUB — SQL-квест (React + alasql)

## Описание

Веб-приложение-квест для поиска "преступника" с помощью SQL-запросов к локальным JSON-таблицам. Интерфейс в стиле МВД/ФСБ, строгий минимализм, адаптивная верстка.

## Основные технологии
- React (Create React App)
- JavaScript
- alasql (SQL-движок для работы с JSON)
- CSS (минималистичный, grid/flex)

## Модульная архитектура
- Каждый уровень — отдельная папка в `src/modules/` (например, `q01`, `q02` и т.д.).
- Внутри уровня: 
  - `tables/` — только осмысленные JSON-таблицы (например, `visitors.json`, `cameras.json`, `exponats.json`)
  - `config.js` — настройки уровня (описание, задача, победный текст, путь к картинке и список таблиц)
- Добавление нового уровня: скопируйте папку, измените таблицы и config.js.

## Структура проекта
- `src/App.js` — основной роутинг и логика
- `src/components/` — компоненты интерфейса (GameModule, LevelSelector)
- `src/modules/q01/` — первый уровень (пример структуры)
- `public/level1.png` — картинка для вводных данных
- `.gitignore` — исключения для git

## Как добавить таблицу в уровень
1. Положить новый JSON-файл в `src/modules/qXX/tables/` (пример: `alerts.json`).
2. Формат: массив объектов (каждый объект — строка таблицы).
3. Добавить имя файла в массив `tables` в config.js уровня.
4. Таблицы автоматически подгружаются и отображаются в интерфейсе.

## Как работает SQL
- Используется alasql, поддерживаются стандартные SQL-запросы (SELECT, WHERE, JOIN и др.).
- Пример: `SELECT * FROM visitors WHERE section = 'Древний Египет'`
- Для победы нужно вывести строку с именем, совпадающим с `victoryText` (см. config.js уровня).

## Победный скрипт
- В каждом уровне в config.js есть переменная `victoryText` (например, "Роман Глухов").
- Если в результате любого запроса появляется это имя — появляется окно победы.

## Кастомизация
- Все тексты и картинка уровня — в config.js.
- Картинка — путь из public (например, `/level1.png`).

## UI
- Сверху три кнопки: Назад, Задача (модалка), Вводные данные (модалка с текстом и картинкой).
- Слева — список таблиц (AVAILABLE TABLES), по центру — история SQL-запросов, справа — заметки пользователя.
- Ввод SQL-запроса снизу, кнопка запуска — круглая с иконкой ▶.

## Для нейросети
- Весь основной код и логика — в компонентах и модулях.
- Для генерации новых уровней — создайте новую папку модуля, таблицы, config.js и картинку.

## Запуск
1. `npm install`
2. `npm start`
