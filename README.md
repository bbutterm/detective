# adHUB — SQL-квест (React + alasql)

## Описание

Веб-приложение-квест для поиска "преступника" с помощью SQL-запросов к локальным JSON-таблицам. Интерфейс в стиле МВД/ФСБ, строгий минимализм, адаптивная верстка.

## Основные технологии
- React (Create React App)
- JavaScript
- alasql (SQL-движок для работы с JSON)
- CSS (минималистичный, grid/flex)

## Структура проекта
- `src/App.js` — основной компонент, вся логика и интерфейс
- `src/tables/` — папка с JSON-таблицами (каждый файл — отдельная таблица)
- `public/level1.png` — картинка для вводных данных (можно заменить)
- `README.md` — это описание
- `.gitignore` — исключения для git

## Как добавить таблицу
1. Положить новый JSON-файл в `src/tables/` (пример: `table4.json`).
2. Формат: массив объектов (каждый объект — строка таблицы).
3. Таблицы автоматически подгружаются и отображаются в интерфейсе.

## Как работает SQL
- Используется alasql, поддерживаются стандартные SQL-запросы (SELECT, WHERE, JOIN и др.).
- Пример: `SELECT * FROM table1 WHERE age > 30`
- Для победы нужно вывести строку с именем, совпадающим с WIN_TEXT (см. App.js).

## Победный скрипт
- В файле App.js есть переменная `WIN_TEXT` (например, "Роман Глухов").
- Если в результате любого запроса появляется это имя — появляется окно победы.

## Кастомизация
- Тексты задачи и вводных данных — переменные `TASK_TEXT` и `INTRO_TEXT` в App.js.
- Картинка вводных данных — переменная `INTRO_IMAGE` (по умолчанию `level1.png` из public).

## UI
- Сверху три кнопки: Назад (заглушка), Задача (модалка), Вводные данные (модалка с текстом и картинкой).
- Слева — список таблиц, по центру — история SQL-запросов, справа — заметки пользователя.
- Ввод SQL-запроса снизу, кнопка запуска — квадратная.

## Для нейросети
- Весь основной код и логика — в App.js.
- Таблицы можно менять/добавлять без изменений кода.
- Для генерации новых уровней — меняй JSON-таблицы, WIN_TEXT, тексты и картинку.

## Запуск
1. `npm install`
2. `npm start`
