## 📋 Описание

Интерактивное веб-приложение-квест для обучения SQL через расследование виртуальных преступлений. Игроки анализируют данные в формате JSON с помощью SQL-запросов, чтобы найти подозреваемых, определить время преступлений и раскрыть сложные дела.

**🎯 Основная цель:** Обучение SQL через геймификацию в стиле детективных расследований.

## 📝 Как работать с модулями

### Создание нового уровня

1. **Создать папку модуля:**
```bash
mkdir src/modules/q02
mkdir src/modules/q02/tables
```

2. **Добавить config.js:**
```javascript
export const levelConfig = {
  title: "Название уровня",
  description: "Краткое описание",
  task: "Подробная задача для игрока",
  briefing: "Вводный текст с контекстом", 
  tables: ["table1", "table2"], // названия JSON файлов
  victoryText: "Правильный ответ", // для проверки победы
  image: "/level2.png" // путь к картинке
};
```

3. **Добавить JSON-таблицы:**
```javascript
// src/modules/q02/tables/suspects.json
[
  {"id": 1, "name": "Иван Иванов", "age": 35, "profession": "Программист"},
  {"id": 2, "name": "Мария Петрова", "age": 28, "profession": "Дизайнер"}
]
```

4. **Зарегистрировать в App.js:**
```javascript
import { levelConfig as q02Config } from './modules/q02/config';

const levelConfigs = {
  q01: q01Config,
  q02: q02Config, // добавить новый уровень
};
```

### Особенности создания данных

**💡 Рекомендации для JSON-таблиц:**
- 10-30 записей на таблицу для реалистичности
- Добавляйте "шумовые" данные, не относящиеся к задаче
- Используйте понятные названия полей на английском
- Связывайте таблицы через общие поля (foreign keys)
- Включайте временные метки для расследований

## ⚡ Система условий победы

### 🎯 **Строгие условия для точного обучения**

Система проверяет не только результат, но и правильность SQL-запроса:

#### **Типы условий:**

1. **`query_contains_and_result`** - основной тип для обучения:
   - Проверяет наличие ключевых слов в запросе (`WHERE`, `ORDER BY`, `LIMIT`)
   - Проверяет точное количество строк в результате
   - Проверяет содержание конкретных значений

2. **`specific_query`** - для бонусных условий:
   - Проверяет точное соответствие SQL-запроса

3. **`row_count`** - количество строк в результате

4. **`contains_value`** - наличие значения в результатах

#### **Примеры строгих условий:**

```javascript
// Уровень 1: Должен использовать WHERE и найти ровно одного искусствоведа
victoryConditions: {
  type: "query_contains_and_result",
  requiredInQuery: "WHERE",
  requiredRowCount: 1,
  requiredValue: "Искусствовед"
}

// Уровень 3: Должен использовать ORDER BY + LIMIT и найти последнего посетителя  
victoryConditions: {
  type: "query_contains_and_result",
  requiredInQuery: ["ORDER BY", "LIMIT"],
  requiredRowCount: 1,
  requiredValue: "Роман Шаров"
}
```

### 🚫 **Что НЕ проходит:**
- `SELECT * FROM visitors` - нет WHERE, много строк
- `SELECT * FROM visitors ORDER BY time_in DESC` - нет LIMIT, много строк
- Неточные запросы без фильтрации

### ✅ **Что проходит:**
- `SELECT * FROM visitors WHERE profession = 'Искусствовед'` - есть WHERE, 1 строка, правильное значение
- `SELECT * FROM visitors ORDER BY time_in DESC LIMIT 1` - есть ORDER BY + LIMIT, 1 строка, нужный человек
